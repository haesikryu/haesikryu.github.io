교안 추가 가이드

이 블로그에 HTML 교육 슬라이드를 등록하는 방법입니다.

1. HTML 폴더 만들기

assets/courses/<id>/index.html 경로에 독립 HTML을 둡니다.

Chirpy 레이아웃 없이 전체 화면으로 서빙됩니다.

2. 목록에 등록

_data/courses.yml에 항목을 추가합니다.

- id: my-course
  title: "제목"
  summary: "한 줄 설명"
  tags: [Tag]
  date: 2026-08-27
  duration: "약 10분"
  href: /assets/courses/my-course/index.html

3. 메뉴에서 확인

사이드바 Lecture → 카드 그리드 → 카드 클릭 시 HTML이 새 탭에서 실행됩니다.
