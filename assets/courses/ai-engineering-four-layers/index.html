AI 엔지니어링 4레이어

Prompt → Context → Harness → Loop

좋은 답변을 넘어, 근거·실행·자동화까지 설계합니다.

한 문장으로

Prompt는 지시, Context는 근거, Harness는 실행·검증, Loop는 목표까지 반복하는 운영 구조입니다.

1. Prompt

무엇을, 어떤 형식으로, 어떤 제약하에 시킬지 정의합니다.

  • 역할 · 목표 · 범위
  • 출력 형식 · 품질 기준
  • 하지 말아야 할 것

2. Context

무엇을 보고 판단할지 — RAG, 사내 문서, 정책, 이력, 도구 설명.

  • 관련성 · 최신성 · 권한
  • 근거 추적 가능해야 함
  • 많을수록 좋지 않음 (고신호만)

3. Harness

도구 연결, 검증, 로깅, 권한 — AI를 시스템처럼 동작하게 만드는 장치.

  • Gateway · Guardrail
  • Evaluation · Observability
  • Prompt / Tool Registry

4. Loop

목표 달성까지 반복·점검·개선. Agentic workflow의 운영 층입니다.

  • 재시도 · 평가 · 승인
  • 안전한 영역부터 자동화
  • 감사 · 롤백 · 거버넌스

중첩 구조

Loop — 목표까지 반복
Harness — 실행·검증·통제
Context — 판단 근거
Prompt — 지시

도입 순서

  1. 프롬프트 표준화
  2. 컨텍스트 / RAG 체계화
  3. 하네스 공통 플랫폼
  4. 검증 루프 → 제한된 자동화
